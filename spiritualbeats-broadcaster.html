Firebase Setup
Connect SpiritualBeats so live state, events, and recordings sync to all listeners automatically

⚡ 3 steps to activate Firebase

1Go to console.firebase.google.com, create a project (e.g. spiritualbeats)
2Project settings → Add app → Web → copy the firebaseConfig object shown
3Open spiritualbeats-broadcaster.html in a text editor, find the YOUR_API_KEY block near the top, replace with your config values
4Do the same in spiritualbeats-listener.html — both files need the same config to read from the same database
Enable in Firebase Console
📡
Realtime Database
Build → Realtime Database → Create Database → Start in test mode. Syncs live on/off state and scheduled events to all listener tabs instantly.
🗄
Firebase Storage
Build → Storage → Get started → Start in test mode. Stores recorded .webm audio files. Free tier: 5 GB storage, 1 GB/day download.

⚠ Test-mode rules expire after 30 days. If recordings download locally but don't appear in the app, your rules have expired. Fix them by going to Firebase Console → Storage → Rules and replacing everything with:

rules_version = '2'; service firebase.storage { match /b/{bucket}/o { match /recordings/{file} { allow read, write: if true; } } }
Then click Publish.
🔒
Security Rules (do this before sharing publicly)
The rules above allow anyone to upload. For a private congregation this is fine — only people you share the broadcaster link with can upload. If you want stricter control, add Firebase Auth and require sign-in.
What syncs automatically
✓Live status — listener app switches to the live player the moment you click Go Live
✓Events — scheduled events appear on the Upcoming tab immediately
✓Recordings — audio uploads to Storage when you stop; listener app shows it within seconds
✓Listener count — each listener tab increments a counter you watch in real time
